# LANChess

**LANChess** is a lightweight, cross-platform chess app that lets you play with friends over a local network (LAN) — perfect for planes, trains, cafés, or even your living room! No Wi-Fi? No problem!

---

## Features

- **Play over LAN** 
  Connect directly to your friends’ devices on the same network.  
  No internet? No problem! Play anywhere using virtual router software like **Connectify**, even on planes or trains.  

- **Cross-platform support** 
  - macOS (Intel + Apple Silicon)  
  - Windows x64  
  - iOS  
  - Android  

- **Easy setup**
  Just run the app, and start a game — no complicated configuration needed.  

- **Polished UI & smooth gameplay**
  Fast, responsive, and designed for maximum fun.

## Installation

### macOS

1. Download the `.dmg` from the [releases](https://github.com/PotatoInfinity/LANChess/releases/tag/macos).  
2. Open the DMG and drag **LANChess.app** to your Applications folder.  
3. Launch the app and start a game!  

> ⚠️ **Important:** macOS cannot create a LAN hotspot for offline LANChess play. You **must rely on at least one Windows or Android device** running a virtual router like Connectify.  

### Windows

1. Download **LANChess Setup 1.0.0.exe** from the [releases](https://github.com/PotatoInfinity/LANChess/releases/tag/windows).
2. Double-click to install.  
3. Launch the app and play offline or on your LAN.

### iOS

1. Download the app from the **App Store**.  
2. Open LANChess and connect to the same LAN or a supported hotspot.  
3. Start a game with friends!  

> ⚠️ **Note for iOS:** To host offline games, your LAN must include at least one Windows or Android device running a virtual router (like Connectify), because iOS cannot host a hotspot for LANChess.  

### Android

1. Download the app from **Google Play**.  
2. Connect to the same LAN or a supported hotspot.  
3. Open LANChess and join or host a game.  

> 💡 Tip: Android devices can also **host a hotspot** for offline LANChess play, making it easy for Mac or iOS users to connect.

## Connectify Setup Guide

For users who want to play **offline without Wi-Fi**:

1. **Install Connectify** on a Windows device.  
2. Launch Connectify and **create a Wi-Fi hotspot**.  
   - Give your hotspot a name (SSID) and password.  
3. Connect other devices (Windows, Android, Mac) to this hotspot.  
4. Open LANChess on all devices and start a game!  

> 💡 **Tip for Macos and iOS users:** You must connect to a **Windows or Android hotspot**, because macOS cannot host a hotspot for offline LANChess play due to system restrictions.  

---

## How to Play

1. Open LANChess on two or more devices connected to the same network (or Connectify hotspot).  
2. One device **hosts the game**, the others join via the network.  
3. Start a chess match and enjoy!  

> Works perfectly without internet — just make sure devices are on the same LAN or hotspot.
